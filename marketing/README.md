# Marketing assets

Sources are generated by `python marketing/build.py` (HTML + `brand.css`),
then exported to PNG at exact platform sizes with headless Chrome:

| Asset | Size (px) | Source | Export |
|---|---|---|---|
| Facebook cover | 820 × 312 | `facebook-cover.html` | `exports/facebook-cover.png` |
| Square post (Facebook / Instagram) | 1080 × 1080 | `social-post.html` | `exports/social-post.png` |
| Link preview (Open Graph) | 1200 × 630 | `link-preview.html` | `exports/link-preview.png` (also `src/app/opengraph-image.png`) |

Export (2× pixel density):

```bash
chrome --headless=new --hide-scrollbars --force-device-scale-factor=2 --virtual-time-budget=10000 --window-size=820,312 --screenshot=marketing/exports/facebook-cover.png file:///ABSOLUTE/PATH/marketing/facebook-cover.html
```

Rules (see `docs/brand-guidelines.md`): one message and one call to action per
asset; no accuracy percentages; the figures in the phone mock-up are
illustrative examples of what the app shows.
